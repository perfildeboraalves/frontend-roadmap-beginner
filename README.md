### 🌎 English Version

### 📝 About the Project

This is my **very first web project**! It is a dynamic, creative, and interactive frontend roadmap designed to help absolute beginners navigate the world of web development. 

Instead of building a traditional project, I decided to create a live platform that guides new developers through HTML, CSS, and JavaScript, centralizing step-by-step tracks, curated study links, YouTube video references, and tips on how to use GitHub and LinkedIn to document their own progress. 

My main goal with this application is to level up my technical skills, master Git workflow, and build a solid portfolio to **land my first Frontend Internship**. 

### 🤖 AI-First Development

I drive my learning and coding with an **AI-First mindset**. This project is a collaborative effort between human creativity and Artificial Intelligence. Throughout this journey, I treat top-tier LLMs like **Gemini** and **Inner AI** as my co-pilots, code reviewers, and tech mentors. This approach enables me to debug smarter, understand architecture faster, and master modern development workflows.

### 📝 Sobre o Projeto

Este é o meu **primeiríssimo projeto web**! É um roteiro (roadmap) de frontend dinâmico, criativo e interativo, desenvolvido para ajudar iniciantes do zero a navegarem no universo do desenvolvimento web. 

Em vez de construir um projeto tradicional, decidi criar uma plataforma viva que guia novos desenvolvedores através do HTML, CSS e JavaScript. O site centraliza um passo a passo de estudos, links de referências, indicações de vídeos do YouTube e dicas de como usar o GitHub e o LinkedIn para documentar o próprio progresso. 

Meu principal objetivo com esta aplicação é elevar minhas habilidades técnicas, dominar o fluxo do Git e construir um portfólio sólido para **conquistar minha primeira vaga de estágio em Frontend**. 

### 🤖 Desenvolvimento AI-First

Eu guio meu aprendizado e desenvolvimento com uma mentalidade **AI-First**. Este projeto é um esforço colaborativo entre a criatividade humana e a Inteligência Artificial. Ao longo desta jornada, utilizo grandes modelos de linguagem como o **Gemini** e a **Inner AI** como meus copilotos de código, revisores e mentores técnicos. Essa abordagem me permite resolver bugs de forma mais inteligente, compreender arquiteturas mais rápido e dominar fluxos de desenvolvimento modernos.
